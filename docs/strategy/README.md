# Strategy Notes

This directory holds product and competitive strategy notes extracted from an
older competitive-research branch and refreshed for current use.

These documents are planning inputs, not public marketing copy. They avoid
hardcoded tool counts, version claims, star counts, benchmark claims, and
absolute competitor statements unless the claim can be re-verified close to
publication.

## Contents

- [Competitive Landscape](competitive-landscape.md): peer categories,
  evaluation axes, and product gaps worth watching.
- [Product Opportunity Roadmap](product-opportunity-roadmap.md): extraction
  slices that can inform future issues without implying committed delivery.
- [Positioning and Messaging](positioning-and-messaging.md): reusable messaging
  patterns, audience notes, and public-use fact checks.
