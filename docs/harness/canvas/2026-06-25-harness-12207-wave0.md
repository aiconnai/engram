# Review Canvas: harness-12207-wave0

Date: 2026-06-25
Owner: Codex
Scope: Apply Wave 0 ISO/IEC/IEEE 12207 harness hardening: strict shell failure behavior and historical sensor measurement.

## Trigger

| Trigger | Evidence |
|---|---|
| Harness script change | `docs/harness/bin/bootstrap.sh`, `docs/harness/bin/lib.sh`, `docs/harness/bin/sensors.sh`, `docs/harness/bin/doctor.sh` are process-critical. |
| Harness gate/process change | `sensors.sh` gains a persistent measurement log and `doctor.sh` validates it. |

## Approaches Considered

| Approach | Decision | Reason |
|---|---|---|
| Replace `.sensors-last` with JSON | Rejected | Would break bootstrap/status compatibility and force a migration before Wave 0. |
| Keep `.sensors-last` and add `.sensors-log` JSONL | Accepted | Preserves current consumers while adding 12207 measurement history. |
| Add `set -e` directly without guards | Rejected | Would violate the bootstrap contract to degrade gracefully when optional files are missing. |
| Add `set -e` with explicit fallbacks | Accepted | Fails closed for real script errors while preserving read-only onboarding behavior. |

## Hot Path Complexity

| Path | Time impact | Space impact | Notes |
|---|---|---|---|
| `bootstrap.sh` | Negligible | None | Still read-only; extra guard avoids source failure. |
| `sensors.sh` completion | O(1) append plus rotation check | Bounded by log rotation | Default retention keeps current log plus five rotated generations. |
| `doctor.sh` | O(n) over current `.sensors-log` | None | Current log is bounded by rotation before append. |

## Edge Cases

| Edge case | Verification plan |
|---|---|
| Missing `lib.sh` during bootstrap | `bootstrap.sh` should still exit 0 and print degraded fields. |
| Sensor exclusion reason includes quotes or whitespace | JSON escaping in `append_sensors_log` should keep `.sensors-log` parseable. |
| Existing `.sensors-last` consumers | `sensors.sh status` and bootstrap should continue reading key/value state. |

## Breakage Risk

| Risk | Impact | Mitigation | Verification |
|---|---|---|---|
| `set -e` changes bootstrap behavior | Session onboarding could abort instead of guiding agent | Guard repo root, `cd`, `source`, and optional commands | `bash docs/harness/bin/bootstrap.sh` |
| Malformed JSONL blocks doctor | Harness self-check fails | Centralize JSON escaping and validate with `doctor.sh` | `bash docs/harness/bin/doctor.sh` |
| Log grows without bound | Long-running repos get fragile parsing/retention | Rotate by byte size and generation count | Force low `SENSORS_LOG_MAX_BYTES` in a targeted run |

## Decision

Proceed:

Reason: The change is small, backward-compatible, and directly addresses the highest-priority 12207 measurement gap while preserving the existing harness surface.
