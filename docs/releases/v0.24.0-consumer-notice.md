## Texto proposto aos consumidores

Estamos preparando Engram Core0.24.0 e os SDKs Python/TypeScript0.7.0.
Antes de atualizar, revisem estes contratos:

- `memory_cache_clear` no modo scoped passa de `{cleared, scope, workspace}` para
  `{success, entries_cleared}`. Atualizem o parsing da resposta; a variante global
  e `search_cache_clear` têm contratos próprios descritos no
  [guia de migração](../migrations/v0.24.0-cache-clear.md).
- Importação Markdown usa revisão/dry-run por padrão nos SDKs, CLI e API Rust.
  A aplicação exige `confirm=true`/`--confirm`; o resultado informa `dry_run`.
  Falhas anteriores ao commit não aplicam o lote; um resultado `unknown` exige
  conferir o banco canônico antes de repetir. Ver
  [importação](../migrations/v0.24.0-markdown-import-security.md).
- Export/import no servidor passam a exigir autorização e diretórios protegidos;
  exportar grava arquivos e não é uma operação read-only. Modos restritos usam a
  raiz administrada `ENGRAM_EXPORT_BASE_DIR`; sem ela, exigem maintenance.
  Links/aliases SQLite e diretórios com ACL ou permissões inseguras são recusados.
  Nomes de arquivos exportados podem mudar pelo codec seguro. Ver
  [exportação](../migrations/v0.24.0-markdown-export-security.md).
- O default de busca nos SDKs é20 resultados. Informem `limit=10` explicitamente
  quando precisarem manter páginas de10 itens. Os demais detalhes estão nas
  [notas SDK0.7.0](v0.7.0-sdk-notes.md).

Planejem uma validação em ambiente de teste com as chamadas e o diretório Markdown
que utilizam. A data e os links dos pacotes serão comunicados após o fechamento
dos gates e a decisão de publicação. Exportar uma pasta não a torna aprovada
para publicação em Git ou para compartilhamento externo.
