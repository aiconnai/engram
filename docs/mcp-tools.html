MCP Tools Catalog

Engram provides 243+ active MCP tools organized into tiers (essential, standard, all). Agents discover and execute these tools natively over stdio or HTTP JSON-RPC 2.0.

memory_create essential

Stores a permanent memory or decision with durable SQLite persistence, full text indexing, vector embeddings, and entity extraction.

Group: core / memory
memory_create_daily essential

Creates an ephemeral scratchpad or session memory that automatically decays and expires after 24 hours.

Group: core / temporal
memory_search essential

Executes 3-way hybrid search (BM25 FTS5 + Dense Cosine Vectors + Fuzzy Levenshtein) fused via Reciprocal Rank Fusion.

Group: search / hybrid
memory_traverse essential

Traverses the entity knowledge graph from a root node up to N hops, resolving bidirectional relations and shared context.

Group: graph / traversal
identity_resolve essential

Resolves ambiguous aliases and entity mentions to a canonical unified identity across multiple workspaces.

Group: identity / resolution
memory_temporal_contradictions standard

Scans a workspace for conflicting decisions or temporal anomalies and generates guided resolution proposals.

Group: quality / conflict
memory_scan_project standard

Scans and ingests project policy files: CLAUDE.md, AGENTS.md, .cursorrules, .aider.conf.yml, and coding conventions.

Group: context / repo
memory_council standard

Executes structured multi-perspective consensus review over proposed decisions before writing them to persistent canonical memory.

Group: council / consensus
quality_report all

Computes 5-component context quality report: clarity, completeness, freshness, consistency, and source trust metrics.

Group: quality / audit
memory_find_path all

Finds the shortest semantic connection path between two arbitrary entities or memories in the knowledge graph.

Group: graph / pathfinding
salience_decay_run all

Executes lifecycle transitions (Active -> Stale -> Archived) and recalculates exponential salience decay scores.

Group: lifecycle / salience
discover_tools essential

Allows dynamic MCP tool surface expansion on demand when an agent requires specialized tools not in the active profile.

Group: meta / discovery
