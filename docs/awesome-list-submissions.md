## Not Submitted

- General security scanner lists: Engram is not a security scanner.
- Browser automation lists: Engram can store browser workflow memory, but does
  not automate browsers.
- Framework-native lists for OpenAI Agents SDK, LangGraph, or FastMCP: Engram
  has integration patterns for these ecosystems, not first-party adapters.
